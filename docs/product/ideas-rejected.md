# Ideas rejected

Newest first. An idea can come back if the reason no longer holds; say what changed.

| Idea | Why not | Date | Revisit if |
| --- | --- | --- | --- |
| Sync regularly while the app is open but no brew is running | Not needed: syncing on open, on return to the app and after changes is enough | 2026-10-25 | Changes from another device are often missed |
| Detect individual pours automatically | Not clear it would help | 2026-10 | A concrete use for per-pour data comes up (for example, the calibration work in #44) |
| Make the TDS card more prominent | TDS is read on the TDS vs extraction chart instead | 2026-10 | The chart turns out to be hard to read while brewing |
| Progress or "remaining" cues while pouring | The target line on the chart is enough | 2026-10 | The target line proves hard to follow while pouring |
| Colour the numbers on the chart axes | Declined by the owner (no reason recorded) | 2026-10 | The axes become hard to tell apart |
| Hide flow values that look implausible | Declined by the owner (no reason recorded) | 2026-10 | Odd flow values become confusing |
| Translate the app into other languages | Only one user, who reads English | 2026-10 | Other people start using it |
| A "Portafilter" weight in Settings | Removed: not used for pour-over | 2026-10-19 | Espresso support is wanted |
