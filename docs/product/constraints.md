# Constraints

## Hard limits

Things that are true because of technology, hardware, platform or cost.

- {{e.g. Bluetooth only works in Chromium-based browsers}}

## Non-goals

Things this product deliberately won't do.

- {{non-goal}}

## Rules

Security, privacy, legal or quality rules every change must follow.

- {{rule}}

## Cost guide

Rough sizing so non-developers can judge ideas.

| Kind of change | Typical size |
| --- | --- |
| Text, labels, colours, layout tweaks | Hours |
| New screen or view using existing data | Days |
| New kind of data, new device, new integration | Weeks, needs a developer conversation |
| Anything touching accounts, payments or stored user data format | Needs discussion |
